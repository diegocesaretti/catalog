# Physical watch test checklist

## Aiming

- Recenter while holding the wrist in a comfortable shooting pose.
- Verify left/right movement is natural.
- Verify up/down movement is natural; toggle **Invert vertical** if needed.
- Test aim sensitivity values 3, 5 and 8.
- Confirm the dot remains inside the goal.

## Snap detector

- In Settings, make ten snaps at normal distance from the watch.
- Note detected snaps and false triggers.
- Repeat with wrist movement, clothing noise, a clap and a table tap.
- Raise sensitivity when snaps are missed.
- Lower sensitivity when false shots occur.

## Game

- Complete a five-shot round.
- Verify goalkeeper dives cover six zones.
- Verify saved shots and goals update the score exactly once.
- Confirm tap-to-shoot works when the microphone is disabled.
- Confirm the game can be exited using the Wear OS system gesture.
